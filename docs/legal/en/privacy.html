Privacy policy

Effective 23 September 2026. Luma is a local Windows app from flydmonkey. You can use it without an account, sign-in, or membership.

What stays on this PC

Recordings are written to the save folder you choose. The default is Videos\Recordings. Screenshots are PNG files you save or copy. Settings, including the optional LAN access key, are stored in %LOCALAPPDATA%\Luma\settings.json on this computer.

Normal use does not upload recordings, screenshots, or that settings file to a vendor cloud. This build does not include an account service or an analytics client.

When capture happens

Screen, window, region, system audio, microphone, and camera capture run only after you start those features, or after a schedule you created starts them. Luma does not begin a recording by itself before that. Live capture and encoding stay on this PC through libobs.

A screenshot is taken only when you use the screenshot control or its hotkey. Text recognition uses the Windows OCR engine on this device. The recognized text is not sent to a Luma server. Copying an image or that text uses the Windows clipboard on this PC.

LAN access

LAN access is off until you turn it on. It listens on your network, at port 12345 unless you change it on the desktop. Devices that can reach that address can open the remote panel. If you set an access key, control routes require that key. The web API does not return the key and cannot change the listen port.

LAN control does not send files to Luma’s servers. Anyone on a network you expose, or anyone who has the key, can start the recording you already armed and can list file names in the save folder. Treat the key like a password and keep it off shared machines.

What this policy does not cover

Files you later copy to another app, a shared folder, or a cloud drive are handled by that destination. Windows itself may apply its own screen, microphone, and camera permissions.
