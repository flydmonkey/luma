## 1. 交给浏览器的一张原图

- [x] 1.1 取图时按虚拟桌面物理像素拷出原图，并在同一次响应里返回这张图的像素尺寸、显示器矩形和可见顶层窗口矩形。用已知显示器原点核对宽高，确认返回的图就是主机像素，不是缩小后的预览
- [x] 1.2 响应发出后主机不保留这张图，也不提供按选区保存、取 PNG 或取消的路由。取图之后主机保存目录没有新 PNG，再对不存在的保存路径请求时不会写出文件

## 2. 局域网接口

- [x] 2.1 只增加取图路由，与现有 `/api/v1` 共用解锁。有访问密钥且未解锁时不返回画面、不写 PNG。密钥为空时可以取图。分别用未解锁和空密钥请求验证
- [x] 2.2 取图不开始、不暂停、不停止录制。录制进行中取图，会话状态仍是同一输出文件的录制中。用状态接口验证
- [x] 2.3 OpenAPI 只写取图路由的请求、响应和未解锁失败，不写保存或复制路由。对照文档里的路径和字段与实际响应一致

## 3. 网页遮罩

- [x] 3.1 录制页模式行增加截图按钮。点它打开遮罩，不改变当前录制模式。先选中窗口模式再点截图，确认窗口模式仍选中，遮罩里是主机静止图而不是浏览器本机屏幕
- [x] 3.2 画布上默认矩形拖拽。有效区域旁出现保存和复制。Esc 和小于 8×8 主机像素的拖拽关掉遮罩，不下载、不改两边剪贴板，也不再请求主机。在页面上各做一次拖拽、Esc 和过小拖拽
- [x] 3.3 窗口模式点击命中返回的窗口矩形后高亮，点空处不出现按钮。整屏模式点击哪台显示器就高亮那一台。各选一次再保存，核对下载的 PNG 范围等于选区的主机像素
- [x] 3.4 保存由浏览器下载 `Luma-Shot-yyyyMMdd-HHmmss.png`，遮罩关闭，期间不再请求主机，主机保存目录和两边剪贴板都不变。复制把同一裁图放入浏览器剪贴板，不下载，不再请求主机。浏览器拒绝下载或拒绝剪贴板时页面提示失败。分别点保存、点复制，并用拒绝下载和拒绝剪贴板的环境看提示
- [x] 3.5 五语表补上截图、保存、复制、取消和失败提示。切换网页五种语言，确认这些字符串都不是缺键原文
