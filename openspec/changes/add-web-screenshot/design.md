## Context

见 `proposal.md` 的 Why。行为以 `specs/web-screenshot/spec.md` 与 `specs/lan-control/spec.md` 为准。

桌面截图已经用虚拟桌面拷屏和本机遮罩完成选区，保存写在主机保存目录。网页是同一台 Windows 主机上的局域网遥控页。浏览器拿不到主机的屏幕采集权限。这次的保存和复制都留在浏览器里。

## Goals / Non-Goals

**Goals:**

- 网页模式行用一个截图动作打开遮罩，不改当前录制模式。
- 遮罩里用主机的一张静止图完成矩形、窗口、整屏选择。
- 保存由浏览器下载裁好的 PNG，复制进入当前浏览器的剪贴板。
- 保存和复制不再请求主机。

**Non-Goals:**

- 把主机画面做成持续视频流。
- 用浏览器采集当前设备的屏幕。
- 从网页触发桌面上的那层遮罩，或改全局热键、托盘、浮动条。
- 让主机保存目录多一张 PNG，或改主机剪贴板。
- 自由套索、画笔、马赛克、文字识别。
- 用 libobs 做这张静止图。

## Decisions

### 主机只交一张原图，保存发生在浏览器

打开遮罩时，主机按虚拟桌面物理像素拷出一整张静止图，连同各显示器和可见顶层窗口的矩形一次返回。图的像素尺寸就是主机尺寸。浏览器把这张图放进画布：显示时可以缩小，裁剪时用原图像素。

保存用画布裁出选区，生成 PNG，交给浏览器下载，文件名为 `Luma-Shot-yyyyMMdd-HHmmss.png`。复制用同一块裁图写入浏览器剪贴板。这两步都不发请求。取消只关遮罩。

主机不再为这张图保留 id，也不提供按选区保存、取 PNG 或取消的路由。取图响应发送后就可以丢掉原图。

不在主机上裁再写保存目录。那样保存会落到主机，而这次要的是正在操作的浏览器所在设备。也不把预览压成小 JPEG 再让浏览器保存，否则下载到的图不是主机像素。

持续推流同样不采用。截图要的是打开遮罩那一瞬间。

### 三个选法和桌面同一套结果

默认矩形拖拽。窗口和整屏是遮罩上的切换。窗口模式用返回的窗口矩形做命中，点中则高亮该矩形；点空处不出现按钮。整屏模式点在哪台显示器的矩形里，就取那一台。小于 8×8 主机像素的拖拽，以及 Esc，直接关掉遮罩，不下载、不改剪贴板。

浏览器拒绝下载或拒绝写入剪贴板时，页面说明失败，不改报成功，也不改走主机。

### 接口只增加取图

取图挂在现有 `/api/v1` 上，与其他控制路由共用解锁。几何和原图放在已有的桌面目录和拷屏旁边，不进 libobs。OpenAPI 只补这一条路由。网页模式行的截图按钮不写入 `mode`，五语表补文案。

## Risks / Trade-offs

- [同一台电脑上用浏览器打开局域网页] → 取图那一瞬间浏览器窗口可能在画面里。遮罩在浏览器中，不会再被拍进去；需要干净画面时先把浏览器挪开再打开遮罩。
- [原图整张传到浏览器] → 多屏画面会比较大。这是为了让浏览器离线裁切并保存主机像素。不再在主机内存里留第二份。
- [窗口列表与画面有一瞬之差] → 几何和静止图在同一次取图里生成，点击只命中这份列表，不再二次枚举。

## Migration Plan

没有要迁移的设置或文件。关掉这条能力时，去掉网页按钮和取图路由即可。主机保存目录不因网页截图而变化。
