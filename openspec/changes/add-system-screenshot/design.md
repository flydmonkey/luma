## Context

见 `proposal.md` 的 Why。行为以 `specs/screenshot/spec.md`、`specs/desktop-app/spec.md` 与 `specs/screen-recording/spec.md` 为准。

Luma 主页模式行现在是显示器、区域、窗口、游戏、录音。实时录制走 libobs。游戏格对应 `game_capture`。本机运行时 Luma 经常以管理员身份启动。

## Goals / Non-Goals

**Goals:**

- 用「截图」换掉主页上的「游戏」格，点它打开选区遮罩，不改当前录制模式。
- 遮罩里完成矩形、窗口或整屏选择后，在选区旁二选一：保存 PNG，或复制到剪贴板。
- 全局热键出厂为 Ctrl+Shift+S，与主页格子走同一条流程。
- 去掉游戏录制在主页和设置中的入口。

**Non-Goals:**

- 托盘菜单或浮动录制条上的截图按钮。
- 自由套索、画笔、马赛克或截图编辑器。
- 把 PNG 列进我的视频。
- 用 libobs 或 Media Foundation 做这张静止图。
- 接管或注销 Win+Shift+S。

## Decisions

### 截图格是动作，不是录制模式

模式行仍是五格：显示器、区域、窗口、截图、录音。前三个加录音继续用现有切换逻辑。截图格是按钮，点下去打开遮罩，已经选中的录制模式保持不变。设置、隐藏的模式列表和局域网接口里去掉游戏。网页和接口拒绝以游戏模式开始录制，目标列表里也不再有游戏项。

### 遮罩按显示器各开一扇

虚拟屏幕的原点可能是负数。每台显示器一扇无边框、置顶、不进任务切换的遮罩，选区在它们之间连续。确认或取消时一起关掉。

默认是矩形拖拽。遮罩上提供窗口和整屏两个切换。窗口模式高亮指针下的可见顶层窗口，点一下取其外接矩形。整屏模式点哪台显示器就取哪台的范围。小于 8×8 物理像素的矩形视为没有形成区域，直接关掉，不出现按钮。Esc 同样直接关掉。

### 选区旁两个按钮

区域、窗口或整屏确定后，遮罩先留着，选区旁边放「保存」和「复制」。点哪一个就先关掉遮罩，再只做那一项。

保存：GDI 按虚拟屏幕物理像素拷出矩形，写成保存目录里的 `Luma-Shot-yyyyMMdd-HHmmss.png`。不写入剪贴板。片库继续只认视频和音频扩展名。

复制：同一张图放入剪贴板，不写 PNG。管理员进程往普通进程剪贴板放图可能被系统拒绝，这时提示失败，不改去写文件。

保存失败时提示，不报成功，也不改剪贴板。

遮罩显示期间给它设置「从捕获中排除」。系统允许时，进行中的录制不会录进遮罩。

### 热键不碰录制状态

热键沿用现有全局热键开关和录入方式。出厂组合键为 Ctrl+Shift+S，不注册 Win+Shift+S。设置缺少该键时按出厂值。恢复默认设置会写回 Ctrl+Shift+S。

录制进行中按下截图热键时，不把主窗口从隐藏位置拉回来，也不关掉浮动录制条。

### 文案

新增字符串走现有五语表：简体中文、繁体中文、英语、日语、韩语。主页和设置里的游戏模式文案去掉。

## Risks / Trade-offs

- [关掉遮罩再拷屏会有一帧闪动] → 接受闪动，换 PNG 或剪贴板图片里没有变暗层。
- [部分采集路径仍会录到遮罩] → 只设置系统排除标记，不把「一定不入画」写成保证。
- [管理员身份下复制失败] → 提示失败，不另写文件。
- [窗口矩形含阴影或被裁切] → 使用窗口外接矩形，不做客户区抠图。
- [去掉游戏录制后，全屏游戏可能只能走窗口模式] → 按已确认的范围接受；窗口模式仍要求先选定窗口。

## Migration Plan

已有 `settings.json` 不需要迁移。读到缺失的截图热键时使用 Ctrl+Shift+S。若其中仍记着游戏模式，启动后回到显示器模式，不打开游戏选择。回退本变更即恢复游戏格并去掉截图入口；已保存的 PNG 留在保存目录。
